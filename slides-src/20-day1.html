Lab 3 · Module 3 · Powerful management queries

Build Your Manager's Query Toolkit

RE
Ruth EllisonProgram Manager, METP · 8:15 AM

Thirty years, and every Monday somebody asks me the same five questions. Build them once, and name them like the question they answer. And when one says "eight Features at risk", don't forward it. Read it.

60 minChoppyShared Queries/Training/P##
03

What's my team working on? What's high priority and incomplete? What got done last sprint? Which Features are at risk? How did the last PI land?

Three query types, three kinds of question

Pick the query type for the question

Flat list

"How many? Which ones?"

Lists, counts and the only type that can be charted.

Tree of work items

"What does this work serve?"

Features with their child stories. Busy vs. what the work bought.

Work items and direct links

"What's missing or blocked?"

Orphans, empty Features, dependencies. Including "does not have" links.

Busy is not boughtA flat count shows how busy a team was. A tree by Feature shows what the work bought.

A flat count shows how busy a team was; a tree by Feature shows what the work bought.

Reef ahead

@CurrentIteration picks a sprint, not a team.

What it does

Resolves to the current sprint of the team named in the query's team parameter. Nothing else. It doesn't filter by team.

What to do

Pair it with an Area Path clause, and check whose calendar the team parameter reads. Then the query stays true next sprint.

The cost of getting it wrongA "my team, this sprint" query that silently returns every team's work, or another team's sprint.

A team whose calendar doesn't include today's sprint uses its next sprint as current. Macros beat typed sprints (Lab 11 shows what a typed sprint does to a dashboard).

Use +21, not +30: it's stable for every course day. The result is a shortlist, not a verdict. Triage before you forward. The data problem foreshadows Lab 11.

Query for what's missing

Progress reports can't see what isn't linked.

Orphans

Stories with no parent: "Only return items that do not have matching links."

Empty Features

Features with no children: Member-to-Member Transfers, value 20.

Flip the operator. If it still says zero, believe it.

Make the chart lie, then make it honest

True data. False story.

What it counts

A pie of item counts weighs a 1-point story like a 13-point one.

When it looks

A trend window can be picked to hide the climb.

What it compares

Two teams' points on one axis. Different currencies.

A % with no deadline

"61% done" hides 36 points left, due this sprint.

The honest versionReport what's left against the time left, over a window that fits the question.

Have pairs build a misleading version of a chart deliberately, then fix it. It's the fastest way to learn to spot it in someone else's deck.
